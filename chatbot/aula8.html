Um chatbot para cada pessoa

O chatbot funciona, mas ainda tem um problema silencioso: ele trata todas as conversas como se fossem da mesma pessoa. Quando isso acontece, nome, gostos e histórico podem se misturar. Aqui nós organizamos a memória para que cada usuário tenha o próprio espaço dentro do sistema.

Pensa em duas pessoas acessando o chatbot ao mesmo tempo. A primeira diz “meu nome é Ana”. A segunda diz “meu nome é Pedro”. Se o nosso back-end, que é a parte em Python que roda no servidor, tiver uma única variável para guardar o perfil, o nome Pedro substitui o nome Ana. Depois, quando Ana volta a perguntar alguma coisa, o chatbot pode chamá-la de Pedro. O erro não está na inteligência artificial. O erro está na forma como guardamos a memória.

Durante os testes, esse problema quase não aparece, porque normalmente só uma pessoa está usando o servidor. Em um uso real, várias pessoas chegam ao mesmo tempo. Se o sistema não separa os usuários, tudo vira uma única conversa grande: nomes, preferências, perguntas, respostas e contexto.

🙋
Mas como o servidor sabe quem é quem, se todo mundo acessa pelo mesmo endereço?

O servidor precisa receber algum identificador. O jeito mais completo seria criar login e senha, mas isso aumentaria muito o tamanho do projeto. Para este momento, usamos uma solução mais simples: um user_id, que é um código único criado para cada navegador que abre o chatbot.

Sabe quando um site lembra que você já visitou uma página, já colocou algo no carrinho ou já pesquisou um produto? Muitas vezes isso acontece porque o navegador guardou um identificador. Esse identificador não precisa ser seu nome. Ele pode ser só uma sequência de letras e números. Para o sistema, isso já basta para diferenciar uma pessoa da outra.

Esse identificador fica no localStorage, que é um pequeno espaço de armazenamento do navegador para um site específico. A primeira vez que a pessoa abre o chatbot, o JavaScript verifica se já existe um chatbot_user_id. Se não existir, ele gera um código novo com crypto.randomUUID() e salva. Nas próximas mensagens, esse mesmo código vai junto para o back-end.

Aqui, chamamos de front-end a parte visual que roda no navegador. Chamamos de back-end a parte em Python que recebe a mensagem, consulta a memória e conversa com a IA.

como a separação funciona
◆o front-end gera ou recupera um user_id salvo no localStorage
◆a cada mensagem, o user_id vai junto no corpo da requisição
◆o back-end usa esse código para encontrar a memória correta
◆cada usuário fica com o próprio perfil e o próprio histórico
◆como a memória ainda está em variável, ela some quando o servidor reinicia

No back-end, trocamos a ideia de uma única memória por um dicionário chamado usuarios. A chave desse dicionário é o user_id. O valor é outro dicionário com o perfil e o histórico daquela pessoa. Assim, quando chega a mensagem da Ana, o sistema mexe só no espaço da Ana. Quando chega a mensagem do Pedro, mexe só no espaço do Pedro.

🙋
E quando testamos pelo /docs, o que acontece se eu não preencher o user_id?

Se não preenchermos, não tem problema. Por isso o campo user_id recebe o valor padrão default. Assim, o teste pelo /docs continua funcionando mesmo sem interface HTML. Quando usamos a tela do chatbot, o front-end envia o identificador real.

Vamos praticar para entender como funciona. No python vamos criar o seguinte arquivo:

056_Exercicio.py
import warnings
import urllib3
import unicodedata
import httpx
import os
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel
from openai import OpenAI
from dotenv import load_dotenv
warnings.filterwarnings("ignore")
urllib3.disable_warnings()
load_dotenv()
app = FastAPI()
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)
client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    http_client=httpx.Client(verify=False)
)
usuarios: dict = {}
def normalizar(texto: str) -> str:
    texto = texto.lower()
    texto = unicodedata.normalize("NFD", texto)
    return "".join(
        c for c in texto
        if unicodedata.category(c) != "Mn"
    )
def pegar_depois(texto_original: str, texto_normalizado: str, marcador: str) -> str:
    posicao = texto_normalizado.find(marcador)
    if posicao == -1:
        return ""
    inicio = posicao + len(marcador)
    return texto_original[inicio:].strip(".,!?:;")
def obter_usuario(user_id: str) -> dict:
    if user_id not in usuarios:
        usuarios[user_id] = {
            "perfil": {"nome": None, "gostos": []},
            "mensagens": [
                {
                    "role": "system",
                    "content": "Você é um assistente direto e objetivo. Responda de forma curta."
                }
            ]
        }
    return usuarios[user_id]
class Pergunta(BaseModel):
    texto: str
    user_id: str | None = "default"
@app.get("/")
def raiz():
    return {"mensagem": "API com separação de usuários funcionando!"}
@app.post("/chat")
def chat(pergunta: Pergunta):
    uid = (pergunta.user_id or "default").strip() or "default"
    usuario = obter_usuario(uid)
    perfil = usuario["perfil"]
    mensagens = usuario["mensagens"]
    texto_usuario = pergunta.texto.strip()
    texto_norm = normalizar(texto_usuario)
    if not texto_usuario:
        return {"resposta": ""}
    if "meu nome e" in texto_norm:
        nome = pegar_depois(texto_usuario, texto_norm, "meu nome e").title()
        perfil["nome"] = nome
        return {"resposta": f"Prazer, {nome}!"}
    if "eu gosto de" in texto_norm:
        gosto = pegar_depois(texto_usuario, texto_norm, "eu gosto de").lower()
        gosto_norm = normalizar(gosto)
        gostos_salvos = [normalizar(g) for g in perfil["gostos"]]
        if gosto_norm not in gostos_salvos:
            perfil["gostos"].append(gosto)
            return {"resposta": f"Anotado! Você gosta de {gosto}."}
        return {"resposta": f"Sei que você gosta de {gosto}!"}
    extra = ""
    if perfil["nome"]:
        extra += f"O nome do usuário é {perfil['nome']}. "
    if perfil["gostos"]:
        extra += f"O usuário gosta de: {', '.join(perfil['gostos'])}. "
    mensagens[0]["content"] = (
        "Você é um assistente direto e objetivo. "
        + extra
        + "Responda de forma curta."
    )
    mensagens.append({"role": "user", "content": texto_usuario})
    try:
        resp = client.chat.completions.create(
            model="gpt-4.1-mini",
            messages=mensagens,
            max_tokens=80,
            temperature=0.3
        )
        texto = resp.choices[0].message.content
    except Exception:
        texto = "Não foi possível processar. Tente novamente."
    mensagens.append({"role": "assistant", "content": texto})
    if len(mensagens) > 10:
        mensagens = [mensagens[0]] + mensagens[-9:]
    usuario["mensagens"] = mensagens
    return {"resposta": texto}
usuarios: dict = {}Guarda todos os usuários. Cada chave é um user_id. Dentro de cada usuário ficam o perfil e o histórico de mensagens.
def obter_usuario(user_id)Busca ou cria a memória. Se o usuário ainda não existe, cria um perfil vazio. Se já existe, devolve o que estava salvo.
def pegar_depois(...)Extrai o valor digitado pelo usuário. Quando a frase tem meu nome é, a função pega apenas o que vem depois dessa parte.
user_id: str | None = "default"Permite testar sem interface. Se o front-end não enviar identificador, o servidor usa default.
usuario["mensagens"] = mensagensGrava o histórico atualizado. Depois de limitar o tamanho da conversa, salvamos a lista de volta no usuário correto.

        pref_norm = normalizar(preferencia)
        preferencias_salvas = [normalizar(p) for p in perfil["preferencias"]]
        if pref_norm not in preferencias_salvas:
            perfil["preferencias"].append(preferencia)
            return {"resposta": f"Anotei sua preferência por {preferencia}."}
        return {"resposta": f"Sim, eu já tenho anotado que você gosta de {preferencia}."}
    mensagens[0]["content"] = montar_system(perfil)
    mensagens.append({"role": "user", "content": texto_usuario})
    try:
        resp = client.chat.completions.create(
            model="gpt-4.1-mini",
            messages=mensagens,
            max_tokens=120,
            temperature=0.4
        )
        texto = resp.choices[0].message.content
    except Exception:
        texto = "Desculpe, tive um problema. Pode repetir?"
    mensagens.append({"role": "assistant", "content": texto})
    if len(mensagens) > 10:
        mensagens = [mensagens[0]] + mensagens[-9:]
    usuario["mensagens"] = mensagens
    return {"resposta": texto}

⚡ exercício 060 - limpeza de memória por usuário

Adicione uma rota que apaga a memória de um usuário específico médio

Crie um chatbot com uma forma de limpar a memória de um único usuário. A rota /chat continua respondendo às mensagens. A nova rota /limpar recebe um user_id e apaga apenas a memória ligada a esse identificador.

Apoio:
class LimparRequest(BaseModel) Define o formato do pedido de limpeza. O FastAPI usa essa classe para entender quais dados devem chegar quando alguém chamar a rota de limpeza.
user_id: str Informa qual usuário será localizado. Como a memória é separada por identificador, o sistema precisa receber o user_id para saber qual espaço deve ser apagado.
@app.post("/limpar") Cria a rota de limpeza. Essa rota não conversa com o chatbot. Ela recebe um pedido separado para apagar a memória ligada a um usuário específico.
def limpar(req: LimparRequest) Executa a limpeza quando a rota é chamada. O parâmetro req representa os dados enviados para a API, seguindo o formato definido em LimparRequest.
uid = req.user_id.strip() Pega o identificador enviado. O strip() remove espaços sobrando no começo ou no fim, evitando erro quando o valor vem como " usuario_1 ".
if uid in usuarios Verifica se esse usuário existe. O código procura o identificador dentro do dicionário usuarios, que guarda as memórias enquanto o servidor está rodando.
del usuarios[uid] Apaga somente a memória desse usuário. Se existirem vários usuários no dicionário, apenas o identificador recebido será removido. As outras memórias continuam separadas.

A rota /limpar remove o usuário do dicionário usuarios. Na mensagem seguinte, a função obter_usuario() cria uma memória nova para aquele mesmo identificador.

⚡ exercício 061 - sistema completo do zero ao produto

Chatbot de ponta a ponta reunindo os principais conceitos desafio

Crie um chatbot que reúna todos os conceitos que você sente que aprendeu. A interface HTML aparece no ZIP da solução para testar o projeto no navegador.

  1. reconhecer algumas frases antes de chamar a IA, como nome, preferência ou pedido de limpeza;
  2. guardar nome e uma informação extra em um perfil separado por usuário;
  3. usar uma instrução principal para definir o papel do chatbot;
  4. manter um histórico de mensagens para cada usuário;
  5. limitar o tamanho do histórico para a conversa não crescer sem controle;
  6. criar a rota /limpar para apagar apenas a memória de um identificador;
  7. ler a chave da API pelo arquivo .env;
  8. tratar erro para a tela não quebrar quando algo falhar;

import warnings
import urllib3
import unicodedata
import httpx
import os
import json
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel
from openai import OpenAI
from dotenv import load_dotenv
warnings.filterwarnings("ignore")
urllib3.disable_warnings()
load_dotenv()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],

client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    http_client=httpx.Client(verify=False)
)
TEMA_BASE = (
    "Contexto: você é o assistente da Livraria Leitura Viva, especializada em literatura brasileira. "
    "Tarefa: ajude o cliente a encontrar livros, responda sobre o acervo e faça sugestões personalizadas. "
    "Formato: respostas em até 3 frases. Quando indicar um livro, responda apenas em JSON no formato "
    "{\"titulo\": str, \"autor\": str, \"motivo\": str}. Sem texto fora do JSON. "
    "Restrições: fale apenas sobre livros e a livraria. Nunca invente ISBNs ou prêmios."
)
usuarios: dict = {}
def normalizar(texto: str) -> str:
    texto = texto.lower()
    texto = unicodedata.normalize("NFD", texto)
    return "".join(
        c for c in texto
        if unicodedata.category(c) != "Mn"
    )

        return ""

def obter_usuario(user_id: str) -> dict:
    if user_id not in usuarios:
        usuarios[user_id] = {
            "perfil": {"nome": None, "generos": []},
            "mensagens": [{"role": "system", "content": TEMA_BASE}]
        }
    return usuarios[user_id]
def montar_system(perfil: dict) -> str:
    contexto = TEMA_BASE
    if perfil["nome"] and perfil["generos"]:
        generos = ", ".join(perfil["generos"])
        contexto += f" Atenda {perfil['nome']}, que gosta de: {generos}. Personalize as sugestões."
    elif perfil["nome"]:
        contexto += f" Atenda {perfil['nome']} com cordialidade."
    return contexto
def resposta_direta(texto_norm: str, perfil: dict) -> str | None:
    if "oi" in texto_norm or "ola" in texto_norm:
        nome = f", {perfil['nome']}" if perfil["nome"] else ""
        return f"Olá{nome}! Bem-vindo à Leitura Viva. Posso indicar um livro ou tirar dúvidas."
    if "tchau" in texto_norm or "ate logo" in texto_norm:
        return "Até a próxima! Boas leituras."
    return None

    texto: str
    user_id: str | None = "default"

    user_id: str

@app.post("/chat")
def chat(pergunta: Pergunta):
    uid = (pergunta.user_id or "default").strip() or "default"
    usuario = obter_usuario(uid)
    perfil = usuario["perfil"]
    mensagens = usuario["mensagens"]
    texto_usuario = pergunta.texto.strip()
    texto_norm = normalizar(texto_usuario)
    if not texto_usuario:
        return {"resposta": ""}
    direta = resposta_direta(texto_norm, perfil)
    if direta:
        return {"resposta": direta}
    if "meu nome e" in texto_norm:
        nome = pegar_depois(texto_usuario, texto_norm, "meu nome e").title()
        perfil["nome"] = nome
        return {"resposta": f"Prazer, {nome}! Qual tipo de leitura você curte?"}
    if "gosto de" in texto_norm:
        genero = pegar_depois(texto_usuario, texto_norm, "gosto de").lower()
        genero_norm = normalizar(genero)
        generos_salvos = [normalizar(g) for g in perfil["generos"]]
        if genero_norm not in generos_salvos:
            perfil["generos"].append(genero)
            return {"resposta": f"Anotei que você curte {genero}!"}
        return {"resposta": f"Sei que você curte {genero}!"}
    mensagens[0]["content"] = montar_system(perfil)
    mensagens.append({"role": "user", "content": texto_usuario})
    try:
        resp = client.chat.completions.create(
            model="gpt-4.1-mini",
            messages=mensagens,
            max_tokens=150,
            temperature=0.4
        )
        raw = resp.choices[0].message.content.strip()
        try:
            dados = json.loads(raw)
            texto = f"Sugestão: {dados['titulo']} de {dados['autor']}. {dados['motivo']}"
        except (json.JSONDecodeError, KeyError):
            texto = raw
    except Exception:
        texto = "Desculpe, tive um problema. Pode repetir?"
    mensagens.append({"role": "assistant", "content": texto})
    if len(mensagens) > 10:
        mensagens = [mensagens[0]] + mensagens[-9:]
    usuario["mensagens"] = mensagens
    return {"resposta": texto}
