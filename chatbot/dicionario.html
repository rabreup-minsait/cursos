Dicionário do curso

Termos técnicos e conceitos que aparecem nas aulas de chatbots com Python, organizados para consulta rápida durante os exercícios e revisões.

A
topo
.envaulas 03, 07
Arquivo usado para guardar variáveis de ambiente do projeto, como OPENAI_API_KEY. Ele evita colocar chaves e senhas diretamente no código. O Python lê esse arquivo com load_dotenv() e acessa os valores com os.getenv().
alucinaçãoaulas 09, 10
Resposta inventada pela IA que parece correta, mas não está apoiada nos dados reais do sistema. Em chatbots com catálogo, FAQ ou base interna, a regra é simples: se o dado não veio da fonte real, a IA não deve inventar.
APIaulas 03, 07
Interface de Programação de Aplicações. É um contrato de comunicação entre sistemas: você envia dados em um formato esperado e recebe uma resposta estruturada. A OpenAI expõe uma API; o FastAPI permite criar a sua.
API keyaula 03
Chave secreta que identifica sua conta ao chamar uma API. No curso, ela fica em OPENAI_API_KEY. Nunca deve aparecer no HTML, no JavaScript público ou em prints.
B
topo
back-endaulas 07 a 10
Parte do sistema que roda no servidor. É onde ficam a chave da API, a chamada à IA, os logs, o catálogo, o FAQ e a memória por usuário. No curso, o back-end é feito em Python com FastAPI.
BaseModelaula 07
Classe do Pydantic usada para declarar o formato dos dados recebidos por uma rota FastAPI. Se a classe pede texto: str, o FastAPI valida automaticamente se esse campo chegou.
breakaula 01
Comando Python que interrompe um loop imediatamente. No chatbot de terminal, é o que permite encerrar o while True quando o usuário digita sair.
C
topo
catálogoaulas 09, 10
Base de dados reais sobre produtos, preços, estoque ou serviços. O catálogo funciona como fonte de verdade: se o item não está nele, o chatbot deve dizer que não encontrou.
classificação de intençãoaulas 02, 09
Etapa que identifica o objetivo da mensagem antes de responder. A pergunta pode ser FAQ, produto, conversa livre, encerramento ou coleta de dados do usuário. Essa decisão escolhe o caminho do código.
config.pyaula 10
Arquivo separado para concentrar configurações do projeto: modelo, temperatura, limite de tokens, nome do bot, log e system prompt base. Isso reduz repetição e facilita manutenção.
CORSaula 07
Cross-Origin Resource Sharing. É uma proteção do navegador que controla se uma página pode chamar uma API em outro endereço. O CORSMiddleware libera a comunicação entre front-end e FastAPI.
D
topo
decoradoraula 07
Linha que começa com @ e registra a função logo abaixo. Em FastAPI, @app.get("/") e @app.post("/chat") transformam funções Python em rotas web.
dicionárionivelamento, aulas 02, 05, 06
Estrutura de dados Python formada por pares de chave e valor. Exemplo: {"nome": "Ana", "idade": 30}. Aparece em perfis, intenções, produtos, FAQ e respostas JSON.
dotenv / load_dotenv()aulas 03, 07
Biblioteca e função usadas para carregar variáveis do arquivo .env. Depois disso, o código consegue ler valores secretos com os.getenv().
E
topo
embeddingaula 08
Representação numérica do significado de um texto. Textos com sentidos parecidos geram vetores próximos. É a base de buscas por similaridade em documentos e Vector Stores.
endpointaulas 07 a 10
Endereço específico de uma API, como /chat, /status ou /. Cada endpoint recebe uma requisição, executa uma função e devolve uma resposta.
F
topo
fallbackaulas 01, 02, 09
Resposta padrão usada quando nenhuma condição específica é encontrada. É o “não entendi” do chatbot, idealmente acompanhado de uma orientação sobre o que o usuário pode perguntar.
FAQaulas 09, 10
Frequently Asked Questions, ou perguntas frequentes. No chatbot, é uma base de perguntas e respostas prontas para dúvidas previsíveis, como horário, endereço, pagamento e troca.
FastAPIaula 07
Framework Python para criar APIs. Ele recebe requisições HTTP, valida dados com Pydantic, executa funções de rota e devolve respostas em JSON. Também cria a página /docs.
fetch()aulas 07, 08
Função JavaScript usada para chamar APIs a partir do navegador. O front-end usa fetch() para mandar a pergunta ao back-end e receber a resposta sem recarregar a página.
front-endaula 07
Parte visual do sistema, executada no navegador. No curso, é a página HTML com campo de mensagem, botão de envio e histórico da conversa.
G
topo
GET / POSTaula 07
Métodos HTTP. GET normalmente busca informação; POST envia dados para processamento, como mandar uma pergunta para a rota /chat.
globalaulas 06, 07
Palavra-chave usada dentro de uma função para indicar que uma variável externa será modificada. Sem global, o Python criaria uma variável local.
H
topo
histórico de mensagensaulas 03, 05, 06
Lista com mensagens anteriores enviadas à IA. Reenviar o histórico dá contexto ao modelo, mas aumenta o consumo de tokens. Por isso o curso também trabalha limite e resumo.
HTTPaula 07
Protocolo usado na web para cliente e servidor trocarem mensagens. Quando o navegador chama o FastAPI, a comunicação acontece por HTTP.
I
topo
if / elif / elsenivelamento, aula 01
Estruturas de decisão do Python. O if testa uma condição; o elif testa outra possibilidade; o else executa quando nenhuma condição anterior foi verdadeira.
indentaçãonivelamento, revisão
Espaços no início da linha que indicam a qual bloco o código pertence. Em Python, a indentação é parte da sintaxe e precisa estar correta depois de def, if, for, while e try.
J
topo
JSONaulas 05, 07
Formato de texto para representar dados estruturados. APIs usam JSON para trocar informações. Em Python, json.loads() transforma texto JSON em dicionário.
L
topo
LGPDaula 06
Lei Geral de Proteção de Dados. No contexto do chatbot, lembra que dados pessoais e sensíveis exigem cuidado antes de serem enviados para uma IA ou serviço externo.
LLMaulas 03, 09
Large Language Model, ou modelo de linguagem de grande escala. É o tipo de IA que gera respostas em linguagem natural a partir do contexto recebido.
localStorageaula 08
Armazenamento persistente do navegador. O curso usa localStorage para guardar o user_id e manter a mesma identidade entre visitas.
loggingaula 10
Módulo nativo do Python para registrar eventos do sistema com data, hora, nível e detalhe. É mais adequado que print() em aplicações reais.
M
topo
max_tokensaula 04
Parâmetro que limita o tamanho máximo da resposta gerada pela IA. Ajuda a controlar custo e manter o chatbot objetivo.
middlewareaula 07
Camada que intercepta requisições e respostas no servidor. O CORSMiddleware é um middleware usado para liberar chamadas vindas do front-end.
modeloaulas 03, 04, 10
Motor de IA escolhido para gerar respostas. No curso aparece como model="gpt-4.1-mini". Modelos diferentes podem ter custos, velocidades e capacidades diferentes.
N
topo
NFDaula 02, revisão
Forma de normalização Unicode que separa letras e acentos. Isso permite remover acentos e comparar textos com mais segurança.
normalizar()aula 02 em diante
Função criada no curso para padronizar texto antes da comparação. Ela costuma converter para minúsculas e remover acentos.
O
topo
os.getenv()aulas 03, 07
Função que lê variáveis de ambiente. No curso, os.getenv("OPENAI_API_KEY") busca a chave da API sem escrevê-la diretamente no código.
P
topo
perfil do usuárioaulas 06, 08
Conjunto de informações guardadas pelo código sobre uma pessoa, como nome, gostos ou histórico. Permite personalização sem depender apenas da memória textual enviada à IA.
promptaulas 03, 04
Texto ou conjunto de mensagens enviado para orientar a IA. Um bom prompt define contexto, tarefa, formato e restrições.
Pydanticaula 07
Biblioteca usada pelo FastAPI para validar dados. Ela garante que a requisição respeite o modelo declarado antes de executar a função da rota.
R
topo
RAGaulas 08, 09
Retrieval Augmented Generation. Padrão em que o sistema busca dados reais primeiro e depois passa esses dados para a IA responder. Ajuda a reduzir alucinações.
requisiçãoaulas 07 a 10
Mensagem enviada de um cliente para um servidor. Pode vir do navegador, de fetch(), de um script Python ou da página /docs.
returnaula 01 em diante
Comando que encerra uma função e devolve um valor. Em rotas FastAPI, o return define o conteúdo da resposta HTTP.
roleaula 03
Papel de uma mensagem enviada ao modelo. Os principais são system, user e assistant.
rotaaula 07
Caminho de uma API associado a uma função, como /chat ou /status. Em FastAPI, uma rota é declarada com decoradores.
S
topo
separação de responsabilidadesaula 10
Prática de dividir o código em partes com papéis claros. Uma função busca FAQ, outra busca produto, outra chama a IA e outra registra logs.
status HTTPaula 07
Código numérico que resume o resultado de uma requisição. 200 indica sucesso, 422 erro de validação e 500 erro interno.
system promptaulas 03, 04, 06, 10
Instrução principal que define quem é o chatbot, como ele deve responder e quais limites deve respeitar. Controla comportamento, tom e segurança.
T
topo
temperatureaula 04
Parâmetro que controla a variação das respostas da IA. Valores baixos tornam a resposta mais previsível; valores altos aumentam criatividade.
tokenaulas 03 a 06
Unidade usada pelos modelos para ler e gerar texto. Entrada e saída consomem tokens, então prompts longos e históricos grandes aumentam custo.
try / exceptaulas 04, 07, revisão
Estrutura usada para lidar com erros. O código dentro de try é executado; se algo falhar, o except captura o erro.
U
topo
unicodedataaula 02
Biblioteca nativa do Python usada para manipular caracteres Unicode. No curso, ela ajuda a remover acentos no processo de normalização.
user_idaula 08
Identificador usado para distinguir usuários. O front-end envia o user_id com cada mensagem; o back-end usa esse valor para separar memória e perfil.
uvicornaula 07
Servidor que executa a aplicação FastAPI. O comando python -m uvicorn arquivo:app --reload inicia o servidor.
V
topo
variávelnivelamento
Nome que aponta para um valor na memória do programa. Exemplo: nome = "Ana". Variáveis permitem guardar dados e reutilizá-los.
Vector Storeaula 08
Banco especializado em guardar vetores de significado e buscar informações por similaridade. Ajuda o chatbot a consultar documentos grandes.
verify=Falseaulas 03, 07, 10
Configuração passada ao cliente HTTP para ignorar verificação de certificado SSL. Pode ajudar em testes, mas não é recomendada em produção.
W
topo
while Trueaula 01
Loop infinito em Python. O chatbot de terminal usa while True para continuar pedindo mensagens até encontrar uma condição de saída.
